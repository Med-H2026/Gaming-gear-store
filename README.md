# NOOB SLAYER 🎮
### Premium Gaming Gear Store

A fully responsive gaming e-commerce website built for esports players in Qatar. 
"Gear up. Dominate. Repeat."

## ✨ Features
- **Hero + Explore Section**: Brand story with neon purple theme
- **Shop Gear**: Category filters + 2-page pagination
- **Best Sellers**: Hot/New badges + discount prices
- **Reviews**: 5 verified buyer testimonials with avatars
- **Sign-In Modal**: Clean login popup
- **Contact Form**: With email, WhatsApp, location
- **Fully Responsive**: Mobile, Tablet, Desktop
- **Smooth Animations**: Hover effects, drop-shadows, transitions

## 🛠️ Tech Stack
HTML5, CSS3, Vanilla JavaScript

## 🚀 How to Run
Just open `index.html` in your browser. No build needed.
